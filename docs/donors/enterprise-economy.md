# Autonomous enterprise pass

The economy wave keeps the existing market as the price/reference layer and
adds firm behavior around it.  Businesses quote from local reference prices,
inventory, markup, and advertising; competition records shares from actual
offers.  Contracts move physical lots and money only when endpoints can fulfill
the agreement.  Loans, repayment, research, and scarcity bids use the same
cash and inventory mutation gateways, so there is no duplicate firm economy.
